# Sentinel-2
Sentinel-2 native satellite products download and processing using Python.
Access CDSE catalogue using CDSE login credentials.
Search for .SAFE archive products intersecting with a shapefiles and within a date range.
Internal connection, reconnection, connection refreshing, and download retrying functionality.
Stores the downloaded metadata and raw .jp2 files in similar structure as SAFE archive.

Provides easier downloading of large amounts of satellite data.
Can be tailored to change cloud cover requirements and for different band acquisitions.
Easy to change date range and provincial/country shapefile to search for products intersecting that area.
